install yourself

download for macOS

signed by sol pbc, notarized by Apple. installs your observer and your journal (where sol tends your memories), then opens the first-run wizard. updates over a signed channel.

the wizard connects a gemini API key. prefer OpenAI or Anthropic? choose the provider in Settings and solstone sets it up for you — no separate command-line tool to install.

building from source? (developer path)

prereqs: xcode command-line tools (xcode-select --install), homebrew (brew.sh), then brew install uv. if you prefer pipx, use pipx install --include-deps 'solstone[journal]' && journal setup.

uv tool install --with-executables-from solstone-journal-host 'solstone[journal]'

prereqs: uv from astral.sh: curl -LsSf https://astral.sh/uv/install.sh | sh. if you prefer pipx, use pipx install --include-deps 'solstone[journal]' && journal setup.

solstone[journal] bundles everything a journal host needs — the default CPU transcription runtime is included and journal setup downloads the model. NVIDIA GPU owners who want GPU-accelerated transcription install solstone[journal-cuda] instead (pick one — not both). uv tool and pipx expose the journal command only with the flag shown above; pip exposes it natively. want only the thin sol client to talk to a journal running elsewhere? uv tool install solstone (no extras), or uvx solstone for a one-shot.

then open http://localhost:5015 — the first-run wizard walks you through setting your identity and connecting a gemini API key. prefer OpenAI or Anthropic? choose the provider in Settings and solstone sets it up for you — no separate command-line tool to install. for a linux observer, see solstone.app/observers.
